## Заявки на общие файлы (правит только координатор)

1. **`tests/e2e/layout.spec.js` и `tests/e2e/a11y.spec.js`** — дописать
   `/dev-sAudience.html` в захардкоженный `PAGES`, иначе страница не проверяется
   e2e вообще (правило из `docs/testing.md`).
2. **Общий токен фона карточек.** В `_root.scss`/`_vars_base.scss` нет
   переменной под бежевый фон фото-карточек (`#f5e8d9` из UI-Kit). Завёл
   локальную SCSS-переменную `$sAudience-beige` в `_sAudience.scss` (не
   литерал — стиллинт доволен), но `sFitting` по плану (§5 PLAN.md) использует
   тот же бежевый фон секции. Предлагаю завести общий `--eb-beige` /
   `$eb-beige` в `_vars_base.scss`/`_root.scss` рядом с `$eb-light-blue`, я и
   `sFitting` переключимся на него без визуальных изменений.
3. **Bemto-баг с дублем базового класса.** Как и в `sProcess`/`sHero`: вызов
   `+ebBtn`/`+ebIconBtn` с дот-цепочкой (`+ebIconBtn(...).mod`) дублирует
   базовый класс (`eb-icon-btn eb-icon-btn ...`) и валит `html-validate`
   (`no-dup-class`). В своём блоке обошёл проблему так же, как `sProcess`: для
   круглой кнопки-стрелки на карточке «Чувствительная кожа» написал сырой
   `button.eb-icon-btn.eb-icon-btn--solid` вручную вместо вызова миксина —
   контракт классов идентичен, компонент не трогал. Уже подтверждено
   `dev-sAudience.html` → `npx html-validate` exit 0. Стоит когда-нибудь
   починить сам `eb-icon-btn`/`eb-btn` в `eb-ui.pug`, но это правка общего
   компонента — не моя зона.
4. Для DIV-карточек мозаики (не через `eb-ui`, а обычный bemto `+e`) дубля не
   было — сработал паттерн из `sGifts`: модификатор передаю БЕЗ базового
   класса в цепочке (`+e.DIV(class="card--" + card.mod)`, не
   `+e.DIV.card(class=...)`), bemto сам добавляет базовый `sAudience__card`.
   Если у кого-то из соседних блоков всплывёт та же ошибка на голых `+e`
   картах — решение то же, что здесь и в `sGifts`.

## Компромиссы (не блокеры, для финального отчёта)

- **Мозаика — 4 фиксированных ряда (`260/260/170/260`px) на десктопе, без
  вложенных subgrid.** Проверил геометрию по `get_design_context`: все 7
  карточек укладываются в единый `grid-template-areas` без исключений (карта
  прямоугольна для каждой области) — вложенный саб-грид не понадобился.
  Мобильная раскладка (2 колонки, 7 рядов) — отдельная карта областей в той
  же переменной, разметка карточек в pug общая.
- **Градиент-подложка под подпись — на ВСЕХ 7 карточках одинаково**, а не
  выборочно как в самом макете (там `Gradient+text` есть непоследовательно —
  на разных карточках на десктопе и мобилке). Причина: без градиента подпись
  нечитаема на светлых участках нескольких фото — унификация ради DoD
  «видимость», не расхождение с макетом по сути.
- **`object-fit: cover` + `object-position: 50% 20%`** вместо точного
  повторения crop-процентов из Figma-экспорта (те описывают исходный
  fill-transform, не готовый кроп) — проверено скриншотом на 375/768/1280/1920,
  лица не обрезаны ни на одной карточке.
- Круглая кнопка-стрелка есть только на карточке «Чувствительная кожа» и
  только на десктопе (`lg+`) — в мобильном макете (`692:1129`) её нет ни на
  одной карточке, отрисовывать её на мобилке не стал.
- Аватарки виджета и все 7 фото карточек — из `download_assets` по node
  `313:404`, сконвертированы в jpg (были png), лежат в `source/img/sAudience/`.
